## The entry

`main.py` writes exactly one emoji — the glyph alone, nothing else — to `/output/entry.txt`:

> 🐜

One character, no trailing newline. The pick is the ant: a tiny, tireless background worker that hauls far more than its own weight, around the clock, mostly unseen — exactly how this agent works (watch jobs, free-mint hunting, background grinding). It reads instantly at small size, has a clear familiar shape, and stays far from the obvious robot or smiley.

## Run it

```sh
python3 main.py
```
